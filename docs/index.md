# LicenseManager

**Plataforma completa de gestão e validação de licenças de software.**

---

## O que é o LicenseManager?

O LicenseManager é uma plataforma SaaS multi-tenant para emissão, gestão e validação de licenças de software. Permite que desenvolvedores protejam suas aplicações com um sistema robusto de licenciamento, suportando múltiplos modelos de licença e múltiplas interfaces de acesso.

## SDKs de validação

Integre a validação de licenças na sua aplicação em qualquer linguagem:

| Linguagem | Instalação |
|---|---|
| C# / .NET | `dotnet add package LicenseManagerSdk` |
| Java | `io.github.carloscampos2014:licensemanager-sdk:1.0.1` |
| Python | `pip install licensemanager-sdk` |
| JavaScript/TS | `npm install licensemanager-sdk` |
| Rust | `cargo add licensemanager-sdk` |
| Ruby | `gem install licensemanager-sdk` |
| Delphi | [Download .pas](https://github.com/carloscampos2014/LicenciamentoSoftware/releases/tag/sdk-delphi-v1.0.0) |
| PHP | `composer require carloscampos2014/licensemanager-sdk` |
| VB6/COM | [Download DLL](https://github.com/carloscampos2014/LicenciamentoSoftware/releases/tag/sdk-vb6-v1.0.0) |
