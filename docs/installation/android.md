# Instalação — Android

## Download

[Download APK](https://github.com/carloscampos2014/LicenciamentoSoftware/releases/tag/android-v1.0)

## Passo 1 — Habilitar fontes desconhecidas

**Android 8.0+:** Configurações → Aplicativos → (app de arquivo) → Instalar apps desconhecidos → Permitir

**Android 7 ou inferior:** Configurações → Segurança → Fontes desconhecidas → Ativar

## Passo 2 — Instalar o APK

1. Transfira o `.apk` para o dispositivo
2. Abra o Gerenciador de arquivos
3. Toque no arquivo `LicenseManager-1.0-android.apk`
4. Toque em **Instalar**

## Requisitos

- Android 5.0 (API 21) ou superior
